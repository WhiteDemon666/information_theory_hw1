# Формат архива `.zmh` (ZMH1)

Архиватор использует **канонический двоичный код Хаффмана** для байтов `0..255`. Файл состоит из заголовка и битового потока. Все многобайтовые целые числа записываются в порядке **big-endian**. Дерево явно не хранится: декодер восстанавливает канонические коды по длинам кодовых слов.

## Заголовок

| Смещение | Размер | Содержимое |
|---|---:|---|
| 0 | 4 байта | Сигнатура `ZMH1` в ASCII |
| 4 | 8 байт | Исходная длина файла в байтах (uint64) |
| 12 | 8 байт | Длина закодированного потока в **полезных битах** (uint64) |
| 20 | 4 байта | CRC32 исходных байтов (uint32) |
| 24 | 2 байта | Количество различных байтов `m` (uint16, от 0 до 256) |
| 26 | `2m` байт | `m` пар `(значение байта, длина его кода)`; оба поля по одному байту |

Размер заголовка равен **`26 + 2m` байт**, от 26 до 538 байт. Пары отсортированы по значениям исходных байтов. Храним только длины; канонический код задаётся сортировкой `(длина, значение байта)` с последовательным присвоением целочисленных кодов.

## Кодированный поток

Кодовые слова записываются подряд, от старших битов к младшим. Каждый полный байт выдаётся немедленно; последний неполный байт дополняется **нулевыми младшими битами**. Декодер читает ровно число полезных битов из заголовка и проверяет, что оставшиеся биты последнего байта нулевые. Размер полезной части архива: `ceil(число_бит / 8)` байт.

## Особые случаи и диагностика

- **Пустой файл:** `m=0`, нулевая исходная длина, нулевая длина потока, CRC32=0; архив содержит только 26-байтовый заголовок.
- **Единственный повторяющийся байт:** `m=1`, длина кода равна одному биту. Поэтому размер полезной части — `ceil(N/8)` байт; средняя длина равна 1 биту, а энтропия — 0.
- **Чужой формат:** неверная сигнатура или недопустимое расширение без явного выходного пути.
- **Обрезанный архив:** файла не хватает на заявленный заголовок или число байтов кодового потока.
- **Повреждённый архив:** невалидная таблица длин, несовместимые поля, неправильное дополнение битов, лишние байты, неверная восстановленная длина или несовпадающая CRC32.

Контрольная сумма **CRC32** выбрана ради простоты, доступности в стандартной библиотеке Python и скорости. Она обнаруживает большинство случайных повреждений, но не является криптографической гарантией отсутствия коллизий.

Для безопасной записи сначала создаётся временный файл в каталоге назначения; после успешного завершения он переименовывается в конечный. По умолчанию существующий выходной файл не перезаписывается; доступен `--force`.

## Названия файлов

При сжатии `example.txt` по умолчанию создаётся `example.txt.zmh` — так после удаления суффикса `.zmh` можно восстановить исходное имя без хранения его в заголовке. Для безопасного восстановления поверх существующего `example.txt` требуется `--force`, либо можно передать `--output restored.txt`.
