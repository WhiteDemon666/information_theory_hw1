# SOURCES.md — использованные источники и генерация

## Система генерации кода

**Источник:** ChatGPT

**Где использовался:** Файлы, в которых для большей части кода использовался ChatGPT помечены в начале меткой #GPT generated. В целом по другим файлам тоже были консультации, что и как лучше написать, но там это было не так существенно. Список файлов и для чего там использовалась генерация, предоставляю ниже

### Список этих файлов

| Файл | Для чего использовалась генерация |
|---|---|
| `main.py` | Командная строка, маршрутизация режимов задач 1.1–1.3, вывод результатов и диагностика |
| `sources/loader.py` | Чтение и валидация JSON, разбор старого и расширенного формата, проверка достижимых контекстов |
| `coding/checks.py` | Представление источников конечными вероятностными автоматами, проверка стационарности и отсутствия памяти через линейную оболочку |
| `archiver/huffman.py` | Двухпроходное кодирование Хаффмана, канонические коды, двоичный контейнер, CRC32, восстановление |
| `tests/test_sources.py` | Тесты источников, вероятностей и ошибочных входов |
| `tests/test_uniform_coding.py` | Тесты типов, рациональных вероятностей ошибок и сравнения с полным перебором на малых примерах |
| `tests/test_uniform_integration.py` | Тесты проверки источников, CLI и асимптотических случаев |
| `tests/test_huffman.py` | Тесты архиватора, round-trip, контрольной суммы и повреждений |
| `tests/measure_huffman.py` | Воспроизводимая генерация пяти файлов и таблицы экспериментов |
